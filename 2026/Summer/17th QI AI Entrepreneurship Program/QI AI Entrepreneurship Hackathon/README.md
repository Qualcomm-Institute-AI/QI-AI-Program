## Overview

The QI AI Entrepreneurship Hackathon is an end-to-end AI service platform development challenge in which teams transform AI/ML technologies into practical, user-facing services. Teams develop AI-powered services that address real-world problems or business opportunities, connecting AI model development with application development, deployment, and user interaction.

The Hackathon emphasizes building a complete AI service platform rather than developing an isolated AI/ML model. A complete service integrates a trained AI model into a functional application that delivers meaningful, AI-driven results to users.

## AI Service Platform Development Requirements

Each team was required to develop a complete, end-to-end AI service platform integrating five core components:

1. **AI Model Development** — using GCP AI tools
2. **AI Service Platform Development** — using Claude Code
3. **Software Development & Version Control** — using GitHub
4. **Cloud Deployment** — using Render or Google Cloud Run
5. **RESTful API & AI Model Integration** — connecting the deployed model to the user-facing platform

```
Problem / Business Opportunity
  → AI-Powered Service Concept
  → Dataset Selection & Preparation
  → AI/ML Model Training & Testing (GCP AI Tools)
  → Model Evaluation, Selection & Enhancement
  → AI Service Platform Development (Claude Code)
  → RESTful API & AI Model Integration
  → Cloud Deployment (Google Cloud Run or Render)
  → AI-Driven Result Delivered to User
```

## Evaluation

Each project was evaluated across 10 criteria (10 points each, 100 points total), covering the service concept, AI model development and evaluation, use of GCP AI tools, platform implementation quality, and presentation. The full rubric and scoring details are on Kaggle — see [Related Pages](#related-pages) below.
